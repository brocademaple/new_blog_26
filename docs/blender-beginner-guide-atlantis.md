# Blender beginner guide for Atlantis Gallery

This guide is written for the actual project file:

`assets/gallery/blender/atlantis-gallery-master-v1.blend`

The master is generated by `scripts/build_atlantis_gallery_master.py`. Treat the script as the reproducible source and the `.blend` as the visual-review surface.

## 1. Open and inspect safely

Before experimenting, use **File → Save As** and save a practice copy under:

`assets/gallery/blender/working/atlantis-gallery-master-v1-practice.blend`

The `working/` directory is intentionally ignored by Git. Avoid overwriting
`atlantis-gallery-master-v1.blend` during practice. The master currently packs
all artwork and PBR textures, so the practice copy remains self-contained.

## 2. The four Blender areas you are seeing

1. **3D Viewport** — the large central area containing the museum.
2. **Outliner** — upper-right object hierarchy. Search names such as `Palace`, `ArchiveOfTides`, or `WaterSurface`.
3. **Properties** — lower-right tabs for object transforms, materials, lights, render settings and world settings.
4. **Timeline** — bottom strip. This project uses specific frames as spatial bookmarks rather than animation frames.

## 3. Move around the scene

| Action | Control |
| --- | --- |
| Orbit | Middle-mouse drag |
| Pan | Shift + middle-mouse drag |
| Zoom | Mouse wheel or trackpad pinch |
| Focus selected object | Numpad `.` |
| Front / side / top | Numpad `1` / `3` / `7` |
| Enter or leave active camera | Numpad `0` |
| Frame entire scene | Home |

If navigation becomes confusing, select a known object in the Outliner and press Numpad `.`.

## 5. Viewport display modes

Press `Z` to open the shading pie:

- **Solid** — fastest; useful for examining shapes.
- **Material Preview** — shows materials and artwork without a full render. In the current setup, `Z`, then `2`, opens this mode.
- **Rendered** — closest to Cycles output but heavier.
- **Wireframe** — useful for understanding mesh density.

Use `Shift + Alt + Z` to hide or restore overlays, cameras, light guides and grid lines.

## 6. Objects, meshes, collections and instances

- An **Object** stores position, rotation and scale.
- A **Mesh** stores vertices, edges and faces.
- A **Material** controls surface appearance.
- A **Collection** groups related objects.
- A **Collection Instance** reuses one source asset many times without duplicating all mesh data.

This scene deliberately instances repeated arches, columns, coral and route elements. Selecting an instance does not mean every visible child is a separate full copy.

Useful search terms in the Outliner:

- `ArchiveOfTides`
- `CliffGallery`
- `Palace`
- `WaterSurface`
- `CausticProjection`
- `GodRayVolume`
- `WarmCoralCluster`
- `DistantFish`
- `REVIEW_CAMERAS`

## 7. Basic transformations

| Action | Shortcut |
| --- | --- |
| Move | `G` |
| Rotate | `R` |
| Scale | `S` |
| Constrain to axis | Press `X`, `Y`, or `Z` after G/R/S |
| Confirm | Left click or Enter |
| Cancel | Esc or right click |
| Undo | Cmd + Z |

Example: select a practice coral, press `G`, then `X`, move the mouse, and click to confirm.

Do not apply transforms, join objects, delete collections or apply every modifier in the master until you understand how the generator rebuilds them.

## 8. Materials in this project

The main visual language uses:

- dark blue-green stone;
- antique gold trim;
- warm coral window emission;
- cyan gallery lighting;
- packed artwork thumbnails;
- procedural water, caustics and volume materials.

To inspect a material:

1. Select an object.
2. Open the red checker-sphere **Material Properties** tab.
3. Read the material name.
4. Switch to the **Shading** workspace only in a practice copy.

`WaterSurface_mat`, `CausticProjection_mat` and `GodRayVolume_mat` are node-based procedural materials. Their appearance depends on node connections, so avoid disconnecting sockets in the master.

## 9. Lights and underwater atmosphere

Three different systems work together:

1. **World and compositor fog** create distance falloff.
2. **Spot and area lights** illuminate buildings, art and coral.
3. **God-ray volume boxes** make underwater shafts visible.

The most important lighting objects include:

- `CausticKey`
- `LeftEcologyShaft`
- `PalaceGoldRim`
- `PalaceNaveCoolFill`
- `PalaceFocalArtworkWarm`
- `ArchiveFacadeWarm`
- `CliffFacadeWarm`

Light power, color, size and cone angle appear in the green-lightbulb **Object Data Properties** tab.

## 10. Render versus viewport

The viewport is an interactive approximation. Final evidence images use Cycles CPU rendering with denoising.

For a first test render:

1. Save a practice copy.
2. Choose a review frame.
3. Press Numpad `0`.
4. Open **Render Properties** and confirm Cycles.
5. Use a low sample count such as 16–32.
6. Choose **Render → Render Image**.

The verified project renders stayed below roughly 400 MB peak Blender render memory. Avoid increasing resolution, samples and multiple Blender instances simultaneously.

## 11. What not to change yet

- Do not export the full 289k-triangle review master directly to the website.
- Do not delete cameras or lights just because their viewport guides look messy; hide overlays instead.
- Do not move artwork outside museum interiors.
- Do not flatten the packed materials before the web-specific copies are created.
- Do not overwrite the generated master with an experimental edit.

## 12. The later web-export workflow

After visual approval, the project will create separate optimized copies for:

1. arrival and route;
2. Archive of Tides;
3. Cliff Gallery;
4. central palace;
5. ecology and ruins;
6. Three.js water, fog, caustics and particles.

The approved master remains the high-fidelity visual source; optimized GLBs are delivery derivatives.

## First practice exercise

1. Save a draft copy.
2. Visit frames 1, 40, 60, 80, 100, 120, 140 and 160.
3. Enter each camera with Numpad `0`.
4. Toggle Solid and Material Preview.
5. Hide and restore overlays.
6. Search for `WaterSurface`, `PalaceMuseumTitle`, and `WarmCoralCluster` in the Outliner.
7. Move one coral in the draft copy, undo it, and save the draft.

Completing this exercise teaches navigation, selection, shading, camera review, transformations and safe file handling without risking the authoritative scene.
